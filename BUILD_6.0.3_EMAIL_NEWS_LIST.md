# Build 6.0.3 — Email News List

Adds the final report article list to each scheduled email body, in plain text and HTML, while retaining DOCX and PDF attachments.

Each article displays section-specific serial number, title, publisher and author, publication date and IST time. HTML titles link to original publisher URLs. Sections match the final report: DoS / ISRO Major News, Space Startups (if present), Relevant Space News (if present). The same final filtered and deduplicated article collection is used.

Retains Build 6.0.2 report-date hotfix, Build 6.0.1 Groq fallback and multilingual PDF validation, existing workflow files and Master Query V8.0. No additional credentials required.
