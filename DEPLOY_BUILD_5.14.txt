BACKGROUND MONITORING
=====================

Primary flow:
  Supabase Cron / GitHub schedule
      -> GitHub Actions
      -> optional official X collector
      -> News refresh
      -> Supabase
      -> analysis
      -> 3 PDFs
      -> evidence ZIPs
      -> email

The process does not depend on Chrome remaining open.


OPTIONAL X AUTOMATION
=====================

x_collector.py uses the official X recent-search API only when X_BEARER_TOKEN
is configured in GitHub Actions secrets. If no token is available, the
background monitor continues with X posts already stored in Supabase.


RECOMMENDED DEPLOYMENT ORDER
============================

1. Replace the four repository-root runtime files.
2. Replace .github/workflows/monitor-every-30-min.yml.
3. Commit to main.
4. Confirm required GitHub Actions secrets/variables are still present.
5. Run one manual GitHub Actions test.
6. Confirm PDF/email output.
7. Confirm the next Supabase/GitHub scheduled run triggers automatically.

Do not commit passwords, Gmail App Passwords, Supabase secret keys,
GitHub PATs, or X bearer tokens to the repository.
